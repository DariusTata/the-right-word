# the-right-word

A Secondary Analysis using NLP of qualitatively coded themes from semi-structured interviews.

**Analysis Presentation Options:**
1. For interactable visualizations [view the notebook](https://nbviewer.org/github/DariusTata/the-right-word/blob/main/hahahehe.ipynb) via nbviewer. I recommend this version.
2. To view in a report format, download the [NLP NLF pdf file](https://github.com/DariusTata/the-right-word/blob/main/NLP%20NLF.pdf) here in GitHub. Note, there is some unsatisfactory formatting in this option due to converssion issues from markdown to pdf. 
3. To view the code, access the [NLP NLF ipynb file](https://github.com/DariusTata/the-right-word/blob/main/NLP%20NLF.ipynb) here in GitHub
