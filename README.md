1. To view the code, access the [NLP NLF ipynb file](https://github.com/DariusTata/the-right-word/blob/main/NLP%20NLF.ipynb) here in GitHub

3. Or for interactable visualizations [view the notebook](https://nbviewer.org/github/DariusTata/the-right-word/blob/main/hahahehe.ipynb) via nbviewer
